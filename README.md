# Concept Car — visualização 3D

Projeto de demonstração visual de um conceito automotivo, desenvolvido para experimentar a apresentação de um modelo 3D diretamente no navegador.

**[Abrir demonstração no GitHub Pages](https://felipe-amorim-dev.github.io/Concept-Car-Design/)**

O arquivo do modelo pode ser consultado em [Concept_Car.stl](assets/Concept_Car.stl). Formatos STL não são imagens e precisam de um visualizador 3D.

## Tecnologias e execução
A página de entrada é `index.html`, com recursos estáticos no diretório `assets`. Para testar, clone o repositório e abra a página usando um servidor HTTP local, por exemplo a extensão Live Server do VS Code.

```bash
git clone https://github.com/Felipe-Amorim-Dev/Concept-Car-Design.git
cd Concept-Car-Design
```

Este projeto é uma demonstração de interface; não há integração comprovada com uma API de backend. O projeto [CAD Viewer](https://github.com/Felipe-Amorim-Dev/CAD-Viewer) é uma biblioteca independente para visualização de arquivos 3D.
